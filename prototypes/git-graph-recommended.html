Session · 实现 Git Graph 拓扑图谱 Claude 3.7 Sonnet (Thinking)
参考 https://github.com/mhutchie/vscode-git-graph 的实现，看看如何解决截图这类问题，就是只有一个点或者单独几个点，而没有下一个点的曲线（项目 thinkrail 的 git 历史）
已对照 vscode-git-graph 源码与 thinkrail 真实 Git 历史完成方案对齐：
  • 问题本质：ce57ffd 是 JetBrains 团队创建的独立 PR 截图分支（5 张 PNG 图片，0 父提交，无任何代码祖先）。在图论拓扑中它本身就是一个孤立点。
  • 推荐解决方案：
    1. 显示远端分支开关：顶部提供 [✓] 显示远端分支 勾选框。默认取消勾选后，所有 28 个无代码祖先的远端截图孤立点瞬间全部隐去，主干呈 100% 平滑连续曲线！
    2. 当前分支范围追踪：下拉菜单增加 当前分支 (Current Branch)，只追溯工作区血缘。
    3. 孤立根节点特征标记：对 0 父提交的孤立提交渲染为微圆角方形节点，并标注 (根提交 · 无父提交)，彻底消除“代码画断了”的误解。
